fltk-help v0.1.0

An out-of-the-box FLTK help page UI component. It provides a ready-to-use tab with a button that opens an HTML document via the system's default browser.

Zero Configuration

Just pass the file name or path. The component automatically resolves the final URL.

MSIX Compatible

Automatically detects MSIX environments and uses the ms-appdata:/// protocol.

No WebView Crashes

Completely avoids Z-order bugs, DPI scaling issues, and native window crashes.

Key Features

  • Smart Fallback Strategy: Pass an absolute path for development, or a file name for production. The library figures it out.
  • Perfect Rendering: The user's default browser handles all CSS, JS, and images flawlessly.
  • 100% Stability: No native window conflicts or embedded WebView crashes.

Installation

Add this to your Cargo.toml:

[dependencies]
fltk = "1.5"
fltk-help = "0.1.0"
webbrowser = "1.0"
dirs = "5.0"

Quick Start

Simply pass your Tabs container, the tab label, and the file name or path.

use fltk::{app, prelude::*, group::{Tabs, Group}, window::Window, frame::Frame};
use fltk_help::HelpPage;

fn main() {
    let app = app::App::default();
    let mut win = Window::new(100, 100, 900, 650, "My App");

    let mut tabs = Tabs::new(10, 10, 880, 630, "");

    // Your normal pages
    let mut tab1 = Group::new(0, 25, 880, 605, "Settings");
    tab1.set_label("Settings");
    tab1.end();

    // The Help Page (One line does it all!)
    // Pass a relative path, file name, or absolute path.
    let _help = HelpPage::create_tab(&mut tabs, "Help", "examples/help.html");

    tabs.end();
    win.end();
    win.show();

    app.run().unwrap();
}

Absolute Path (For Local Development)

When you want to test your local HTML file without interference from old cached files in AppData, pass an absolute path:

let abs_path = format!("{}/examples/help.html", env!("CARGO_MANIFEST_DIR"));
let _help = HelpPage::create_tab(&mut tabs, "Help", &abs_path);

AppData (For Production / MSIX)

In production (especially MSIX packaged apps), pass just the file name. The library will automatically look for it in AppData/Local/MyApp/ and use the ms-appdata:/// protocol.

// Assumes "help.html" has been deployed to AppData by your installer/app-initializer
let _help = HelpPage::create_tab(&mut tabs, "Help", "help.html");

Path Resolution Logic

How does the library decide what to open?

  1. If Absolute Path: If the file exists, it is used directly.
  2. If File Name / Relative Path: It first checks AppData/Local/MyApp. If found, it is used.
  3. Fallback: If not found in AppData, it falls back to the relative path in your current working directory.
  4. MSIX Detection: If running in an MSIX sandbox (detected via WindowsApps in the exe path), it generates an ms-appdata:/// URL instead of file:///.

Why no WebView?

Embedding native WebViews (like WebView2) inside FLTK windows is notoriously difficult on Windows. It often leads to:

  • Z-order issues (the WebView covers your buttons and tabs).
  • DPI scaling problems (UI becomes misaligned at 125% / 150% scaling).
  • Fatal crashes when the host window is hidden or resized.

By using the system browser, fltk-help completely eliminates these problems while still allowing you to write complex help documentation with external CSS, JS, and images.
